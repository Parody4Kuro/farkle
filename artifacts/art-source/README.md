# Tavern Bones art sources

The four characters and player hands are locally exported skeletal GLBs, built from the **official MakeHuman CC0 base mesh and CC0 system pack** using MPFB 2.0.17 and Blender 4.5.14 LTS. No third-party game assets or community assets with different licenses are included.

- [MakeHuman export licensing](https://static.makehumancommunity.org/makehuman/faq/are_makehuman_files_free.html)
- [MPFB source at v2.0.17](https://github.com/makehumancommunity/mpfb2/tree/v2.0.17)
- [Official CC0 system pack](https://files2.makehumancommunity.org/asset_packs/makehuman_system_assets/makehuman_system_assets_cc0.zip)
- [Poly Haven CC0 license](https://polyhaven.com/license)

`licenses/MakeHuman-CC0.md` contains the asset license; individual original `.mhmat` / `.mhclo` files retain their provenance. The authoring applications have their own software licenses and are not shipped with the game. Exported assets do not require Blender or MPFB at runtime.

`manifest.json` records tool/archive checksums and final model/source hashes. `materials.json` records each wood, leather and fabric map. `licenses/lebombo.json` records the local 1K indoor HDR environment. All runtime maps and models are under `public/art/`, copied into `dist/art/` and the Mac application.

## Editable contents

Each `.blend` contains the shaped anatomy, GameEngine skeleton with finger joints, packed textures, original garments/cuffs/collars/accessories, three expression morphs and nine original animation clips (idle, inspect, shake, pour, collect, bank, bust, victory, defeat). The game applies arm contact IK and character-specific expressions on top. `player-hands.blend` retains the same anatomical hands, sleeves and rig. The environment and props are parameterized in `src/scene/`; the physically recessed pip surface is generated by `materials.ts`.

The GLB models, editable `.blend` sources, WebM recordings and Mac ZIP are tracked with Git LFS. After cloning, run `git lfs install --local` and `git lfs pull` before building; the packaged Mac application already contains the full assets.

## Rebuild

1. Obtain Blender 4.5 LTS and the pinned official MPFB source above. Package the contents of its `src/mpfb` directory as an extension ZIP and install it into a separate Blender profile using Blender's `extension install-file --repo user_default --enable` command. MPFB is imported as `bl_ext.user_default.mpfb`.
2. Extract the official system-asset ZIP into a temporary directory.
3. Run `python3 scripts/fetch-tavern-materials.py` to reproduce the local maps (hash-checked).
4. Run Blender in background with `BLENDER_USER_RESOURCES` pointing at that authoring profile and `TAVERN_MH_ASSETS` at the extracted system pack: `Blender --background --python scripts/build-tavern-characters.py`. Optional `TAVERN_CHARACTER=mara` rebuilds just one character and player hands.
5. Run `npm run generate:trajectories`, then the normal tests/lint/build. Model alpha modes are normalized after export so opaque skin and transparent cornea/hair sort correctly. Blender backup files and downloaded authoring tools are regenerable caches, not deliverables.

The MakeHuman base/skin/eyes/hair are CC0. Tavern Bones character identities, costumes, headwear, insignia, scene, pip carvings and motion curves are project-authored modifications. No external audio was used; all cues remain procedural Web Audio.
