# 整备、键盘与好友直连

整备界面由固定骰盅、合并数量的行囊和当前物品详情组成。先选槽位，再选行囊物品即可替换；连续选两个同类槽位可以交换。行囊独立滚动，详情显示效果、概率和不可装备原因。可一次恢复六颗公平骰，徽章可卸下。冒险按实际持有数量限制装备，最多两枚不同徽章、其中一个核心；经典保留原有完整骰子和普通徽章配置规则。入座后使用独立配置快照，整备只修改下一局草稿。

局内常驻双方比分、目标、本回合分、本次选择分和主要操作。详细组合、Joker 替代和精确风险在可展开明细中，完整锁定历史仍在托盘详情中。徽章显示被动状态或剩余次数，旁边的详情按钮解释效果和不可用原因。

## 键盘

| 按键 | 操作 |
| --- | --- |
| 1–7 | 选择或取消本次投掷的对应骰子，编号选择后保留 |
| 方向键 | 在当前骰组移动焦点；整备中移动到相邻操作 |
| E / 空格 | 切换焦点骰子；整备中 E 操作焦点按钮 |
| F | 首投，或锁定合法选择后继续 |
| 按住 Q 400 毫秒 | 落袋，显示进度；提前松开、切换焦点、失焦会取消 |
| R / Shift+R | 按装备顺序使用第一 / 第二项主动能力 |
| T | 查看规则 |
| Esc | 关闭面板；没有面板时暂停 |
| Tab / Shift+Tab、Enter | 保留原生焦点导航和按钮操作 |

鼠标落袋仍然直接生效。输入框、弹窗及输入法组合输入期间不响应局内快捷键。投掷、对手回合、冻结选择、断线与暂停均沿用按钮的可用性判断；按住 F 或 R 不会重复执行。3D 与 2D 共用骰子 ID 和编号。

## 和朋友开始一局

1. 双方打开“好友对战”。房主点击“创建对局并生成邀请”。
2. 房主复制完整连接文本，经常用聊天工具发给朋友。
3. 朋友粘贴邀请，点击“使用邀请，生成回应”，将回应发回房主。
4. 房主粘贴回应并连接；界面显示“已直连”后配置本局。
5. 双方点击“准备好了”开始。配置或任一方装备变化会取消双方准备。

公平局默认双方六颗公平骰、无徽章、4000 分，房主可改为现有目标档位。自由局双方共享完整装备目录，每种骰子最多六颗，两枚不同徽章且最多一个核心，不依赖冒险解锁。可展开查看双方完整装备。首局房主先手，再来一局交替先手。

无需部署房间或信令服务器。邀请和回应各包含完整 SDP 与网络候选；使用 Cloudflare STUN 和 Google STUN 收集可连接地址。没有 TURN 中继，部分企业网络、运营商 NAT 或防火墙组合无法建立直连。收集信息最多等待 15 秒，开始连接后最多等待 30 秒，失败后重新交换文本或更换网络。人工复制邀请的等待时间不计入房主连接超时；朋友生成回应后应及时发回。

双方应保持原窗口开启。切走窗口、最小化或看规则只暂停自己的画面、声音和输入，网络仍接收最新状态，房主仍可处理朋友的操作。回来后点击“继续”；没有回合倒计时。

真实断线会暂停操作。双方原窗口仍在时，由原房主生成新的重连邀请，重新交换邀请与回应，恢复完整权威快照。不会重新抽骰或重复落袋。刷新、关窗和主动离开结束当前会话，不做跨重启续局、房主迁移或排行榜。单机存档与统计不受好友局影响。

## 实现边界

`DuelState` 使用固定 host / guest 席位分别保存骰组、比分和徽章次数。当前行动者适配到现有纯规则的 human 视角，复用 Modifier、DFS 计分、完整消费选择、Hot Dice、Bank 与七骰限制。

双方发送 `MatchCommand` 操作意图。房主验证席位、阶段、选择 ID 与版本，仅在房主用现有权重函数抽样一次，并广播状态。客户端不提交分数或骰面。消息携带会话、连接代次、命令 ID 和状态版本；重复命令不重复计分，过期命令返回最新状态，握手检查协议与规则版本。选择预览即时显示，最终计分以房主确认的选择 ID 为准。

网络状态独立于动画时钟，恢复窗口取消过时演出并追到最新局面。Mac 继续使用原有沙箱、上下文隔离、Web 安全和稳定存档路径，没有增加任意 IPC 或关闭安全检查。

这是朋友之间互信的直连玩法，未实现抵抗改版客户端或房主作弊的竞技协议。邀请文本包含本次连接凭据，仅发送给要一起玩的朋友。
