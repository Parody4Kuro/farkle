# Tavern Bones v0.1.0

首个 GitHub Release，包含完整的 Apple Silicon Mac 离线应用。

## 下载与安装

在本版本的 Assets 中下载 **`Tavern-Bones-mac-arm64.zip`**，解压后将 `Tavern Bones.app` 拖入“应用程序”，双击运行。游戏无需 Node.js、终端或网络；GitHub 自动生成的 Source code 附件仅供开发使用。

| 附件 | 用途 |
| --- | --- |
| `Tavern-Bones-mac-arm64.zip` | Apple Silicon Mac 应用 |
| `manifest.json` | 应用版本、源码提交与文件哈希 |
| `SHA256SUMS.txt` | ZIP 与清单的 SHA-256 校验值 |

将三个附件下载到同一目录，在该目录执行 `shasum -a 256 -c SHA256SUMS.txt` 可验证下载完整性。此版本使用 ad-hoc 签名，未经过 Apple 公证；如 macOS 阻止首次打开，可按 [Apple 官方说明](https://support.apple.com/en-au/102445)在“系统设置 → 隐私与安全性”中检查并允许打开。

## 本版内容

- 第一人称“四桌一夜”冒险、经典对局、特殊骰与徽章组合。
- 原创 3D 酒馆、真实物理掷骰、程序化音效；不支持 WebGL 时提供 2D 降级。
- 自动本地存档、退出恢复、失焦和最小化暂停。
- 修复基础公平骰持有不足：始终拥有 6 颗基础公平骰，特殊骰额外持有，旧存档读取时补足。
- 入座前可更换骰子、恢复全公平骰、调整或卸下徽章，显示持有和装备数量。
- 新一夜的铜筹账簿采用计分 v2：三颗 1 为 500 分，三颗 5 为 250 分。

## 升级与兼容

退出旧应用后替换 `.app` 即可。存档保存在 `~/Library/Application Support/Tavern Bones/`，更新应用保留进度；发布包不包含任何个人存档。

已经开始的旧一夜继续使用原计分版本，开始新一夜才采用新规则。继续旧一夜时看到旧分数并非应用缓存。此版本仅提供 macOS arm64 包，不提供 Intel 包或自动更新。

## 仓库整理

首页新增最新版下载入口，文档集中索引，更新记录和发布说明纳入版本控制。`src/`、`desktop/`、`dist/` 和 `artifacts/macos/` 分别保存源码、桌面壳、网页构建和最新 Mac 归档；历史版本保存在 Releases。Git LFS 继续保存最新 Mac ZIP，Release 附件可直接下载。
