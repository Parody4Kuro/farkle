# 构筑重玩性与 Mac 应用验证记录

日期：2026-09-12。实施基线为 `e5fc3e9`，此前 19 个文件、102 项测试通过。本文记录本次功能更新，历史渲染采样单独保留。

## 规则、存档与运行控制

- Vitest：23 个测试文件、136 项测试通过。覆盖装备生效后的 DFS、完整消费与七骰限制、两种模式能力一致性、奖励去重、持有数量与入座快照、同桌重试、v1 迁移与损坏 v2 的读取优先级。
- 暂停覆盖玩家投骰、AI 检查/选骰/决策、Hot Dice、爆骰、护符重投和交接；假时钟越过旧超时时长后，结果、随机流与待执行身份保持一致。恢复只完成一次，暂停中的新游戏或卸载取消旧任务。
- 音效覆盖暂停后停止已调度声源与环境声，以及正在恢复 AudioContext 时再次暂停的竞态。
- Oxlint 与 TypeScript/Vite 生产构建通过。3D 分包仍有原有的 500 kB 体积提示；没有为消除提示而隐藏警告。
- 本轮未增加后端、远程素材、永久数值升级或新奖励数量。经典模式保留原有四种徽章的自由配置与独立统计。

## 浏览器与界面

Chrome、Edge、Firefox、WebKit 共 84 个场景已全部取得通过结果：完整套件用时 7.5 分钟，初轮 83 通过；WebKit 键盘测试改用 macOS 的 Option-Tab，并按原生下拉框的输入前缀超时分隔两次数字选择，专项复验通过（2.8 秒）。游戏未为这次测试调整规则，也未使用程序化聚焦、选项赋值或强制点击绕过键盘操作。最后的规则文案与焦点样式另经应用内浏览器操作复核并重新构建。

每个引擎包含 21 个场景：新夜核心选择、背包领奖与换装、普通桌及老板桌首败重试、七骰刷新恢复、旧档迁移、损坏存档容错、公开对手与视角、Worker/WebGL 降级、实际轨迹暂停超过 6 秒、经典 Hot Dice 和能力，以及三个桌面尺寸。

完整一夜辅助脚本通过可见控件执行真实加权投掷、装备评分、奖励入包、换装、重试与通关，没有通过写入最终比分跳过对局。单独的键盘流程从大厅开始，用 Tab / Shift+Tab（macOS WebKit 使用 Option-Tab）、回车、空格和下拉框数字选项，完成核心换出换回、选骰落袋、领奖换装、暂停和继续。

代理在应用内浏览器中目视检查了核心卡片、整备和暂停界面；1280×720 下入座按钮完整可见、面板没有重叠。规则说明标出冒险核心、同桌重试和手动继续；实际操作确认关闭规则后仍暂停。这个检查不等于项目主人的个人试玩，也不是发行版 Safari 的人工验收。

## 构筑模拟

最终参数共验证 2160 个不同的整夜配置与种子组合、22800 次单桌配置与种子组合，覆盖三种核心、三种起始套装、三种风险阈值及可达装备。全部结束，抽样存档一致性断言通过。重复运行的常规整夜未重复计数，开发原型另存档。

罗盘原型在没有 Joker 的第一桌明显偏弱，因此调整顺子收益与普通同点代价后再做独立种子验证。分析、当前倍率、复现命令、尚未解决的强度与策略深度问题见 [构筑验证](build-validation.md)。自动化不能确认“值得反复玩”；六夜个人试玩表保留待填写。

## Mac 本地应用

最新应用已重新构建；`codesign --verify --deep --strict` 验证通过，使用本机 ad-hoc 签名，未做 Developer ID 签名与 Apple 公证。文件内容为 304,113,864 字节（290.0 MiB / 304.1 MB）。7 个桌面场景均已有通过结果：最后一次完整套件中 5 项通过，两项在原生窗口被外部操作移出前台后按设计暂停；测试驱动补全每次继续操作前的前台激活，AI/奖励恢复和完整离线一夜的专项复验均通过（合计 58.8 秒）。

本轮先修正两项测试前提：装载新存档样例前先从可见控件退出当前对局，避免真实失焦自动保存覆盖测试样例；协议注入的鼠标点击可能到达未激活的 Mac 应用，因此测试先激活原生窗口，再通过可见“继续”按钮恢复。诊断确认原生窗口失焦而网页仍报告有焦点时，游戏正确保持暂停。生产代码没有为测试移除原生焦点保护。

验证直接启动 `release/mac-arm64/Tavern Bones.app`，页面设为离线，测试存档隔离在被 Git 忽略的 `test-results/desktop/`。应用使用 Electron 44.3.0、electron-builder 26.15.3，平台为当前 Apple Silicon Mac、macOS 26.6.2。

7 项覆盖：真实 WebGL/物理 Worker/七骰/音效/键盘/全屏、待演出退出与选择恢复、AI 落袋及奖励幂等恢复、关闭窗口/Dock 重开/单实例、移动与替换应用、可见控件完成离线整夜、原生失焦冻结投骰与最小化冻结 AI。原生冻结用例越过 6500 ms 后比较完整当夜状态，返回窗口仍需点击继续；该场景最后一次完整回归用时 17.8 秒。完整离线一夜最后一次用时 51.3 秒（自动化快速演出，不代表真人整夜时长）。

应用使用固定 `tavern://game/` 源、上下文隔离、沙箱和只读焦点/可见性接口。数据仍保存在 `~/Library/Application Support/Tavern Bones/`，移动或替换应用不改变存档位置。经典模式只恢复设置与统计，冒险恢复对局后等待手动继续。

## 复验

依次运行 `npm test`、`npm run lint`、`npm run build`，再运行 `npm run test:browser`。首次运行浏览器用例前，按 README 安装所需测试引擎。

Mac 应用另运行 `npm run test:desktop`，它会先生成最新应用再执行桌面测试。浏览器与桌面测试结果分别写入 `test-results/browser/` 和 `test-results/desktop/`，避免清理彼此的存档与截图。
