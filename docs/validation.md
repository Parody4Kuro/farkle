## Mac 本地应用（2026-09-12）

- 平台：当前 Apple Silicon Mac，macOS 26.6.2；Electron 44.3.0，electron-builder 26.15.3。
- 产物：`release/mac-arm64/Tavern Bones.app`，文件内容约 290 MiB（约 304 MB）；实际磁盘占用随文件系统计量有所不同。应用仅包含生产资源与桌面外壳，不包含项目源码、测试目录或 `node_modules`。
- 本机 ad-hoc 签名通过 `codesign --verify --deep --strict`；未执行 Developer ID 签名或 Apple 公证，定位为本机自用版本。
- 桌面测试直接启动打包后的 `.app`，将页面置为离线状态；运行时也禁止 HTTP/WebSocket 请求。物理 Worker 返回真实模拟轨迹、WebGL 画布和七骰交互均已验证。
- 桌面套件 6 个场景全部通过（1.1 分钟）：离线渲染/音效/键盘/全屏、投骰中退出与选择恢复、AI 与奖励只结算一次、窗口关闭与 Dock 恢复/单实例、移动与替换应用、完整四桌通关。每个场景使用隔离的存档目录。
- 原生最小化通知与页面可见性合并处理，避免窗口已经收起但页面仍报告可见时继续播放音效。浏览器行为保持兼容。
- 已另外通过普通 Mac 应用启动方式打开并检查真实窗口。测试进度不会带入用户存档，桌面初始收藏为 0。

最终桌面套件记录了 13 次进程启动，到首页标题可见的中位时间为 420 ms，范围为 379–2944 ms，记录保存在 `test-results/desktop/*/startup.jsonl`。这些是当前设备上的自动化采样，包含系统缓存和同时运行测试的影响，不代表冷启动、3D 完全就绪或其他 Mac 的性能。

## 复验

依次运行 `npm test`、`npm run lint`、`npm run build`，再运行 `npm run test:browser`。首次运行浏览器用例前，按 README 安装所需测试引擎。

Mac 应用另运行 `npm run test:desktop`，它会先生成最新应用再执行桌面测试。浏览器与桌面测试结果分别写入 `test-results/browser/` 和 `test-results/desktop/`，避免清理彼此的存档与截图。
